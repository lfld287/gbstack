# 原型

**硬门禁**　Coordinator 对设计决策负责。原型是一次性丢弃物（throwaway），正式实现必须转 `feature`。本剧本以最快取得决策证据为先，放宽最小改动与测试门槛，省去重抽象和正式测试。

1. **界定单一待决分叉。** 写清可选方向和要比较的现象。没有待决分叉就跳过原型，直接转 `feature`。
2. **隔离搭建。** 在独立临时目录工作，严禁污染生产源码。视觉用最轻量的原生 HTML/CSS/JS，行为或时序用最小脚本。
3. **统一切换。** 将多个候选方案放进同一个切换器，用按钮或按键在相同条件下对比。
4. **实测差异。** 在真实界面操作，记录观测、截图或计时结果。观测即测试，无需写断言。
5. **交付决策。** 列出探索变体、实测证据、权衡表、推荐方案及临时目录路径，明确声明原型为 throwaway。选定方向后转 `feature` 正式实现，跨边界时先用 [`architect`](../../architect/SKILL.md) 定型。若所有方案均被否决，Coordinator 须告知用户临时目录路径，并向用户确认保留还是删除。
