# 用专家视角重写 prompt

加深现有目标所需的取证、方法和验证，禁止无端扩大任务范围。

## 1. 先给四项专家视角分析

1. 该领域顶尖专家会做、用户尚未提出且服务于原目标的事。
2. 专家会直接上手的最原始材料（`rawest material`），跳过消化后的二手摘要。
3. 具体的专业方法与工具，以及各自回答的问题。
4. 独立于用户和 agent 的外部验收标准，以及用什么证据证明达标。

## 2. 重写 prompt

- 把四项分析写成原范围内可执行的要求，明确原始输入、方法、外部验收标准和交付物。单机与 Swarm 都可直接使用。Swarm 由 Coordinator 将同一目标与验收标准交给执行者。
- 要求执行 agent 对可通过实验决断的选型先做最小原型，再按可复验的观测结果给出推荐。
- 无法靠实验解决的产品或偏好选择，列明选项和影响，交用户拍板。禁止替用户决定纯产品或偏好问题。

## 输出

先列四项前置分析，再给完整的重写 prompt。
